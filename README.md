# Maung Lab

ဘောလုံးပွဲ ခန့်မှန်းချက် website — ရလဒ်၊ ဘော်ဒီ (Asian Handicap)၊ ဂိုးပေါင်း၊ Corners၊ Fouls။

- `index.html` — app တစ်ခုလုံး (static, build မလို)
- `data/index.json` — ရှိတဲ့ ရက်စွဲစာရင်း
- `data/days/YYYY-MM-DD.json` — တစ်ရက်စာ ပွဲစဉ်နဲ့ stats

Data ကို နေ့စဉ် scheduled task က update လုပ်ပြီး push လုပ်ပါတယ်။ GitHub Pages ကနေ `main` branch root ကို serve လုပ်ပါတယ်။

ခန့်မှန်းချက်များသာ ဖြစ်ပြီး အာမခံချက် မဟုတ်ပါ။
